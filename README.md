# Конфигуратор параметров bitrix-компонентов

Библиотека предназначена для конфигурирования параметров компонента в объектном стиле. Текущий функционал позволяет сформировать статичный параметры по всем типам кроме `CUSTOM`, `SEF_MODE`.

Пример использования конфигуратор можно посмотреть в файле `examples/components/example.list/.parameters.php`
